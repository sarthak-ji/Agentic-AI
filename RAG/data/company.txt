Lumiq AI is an AI-powered application designed
to help users retrieve relevant information.

The application uses Retrieval-Augmented Generation,
also known as RAG, to answer questions based on
external knowledge sources.

RAG combines document retrieval with a language model.
First, the system retrieves relevant information.
Then, the language model uses that information
to generate an answer.

Document chunking divides large documents into
smaller pieces of text.

Embeddings represent text as numerical vectors.
These vectors help the system find semantically
similar information.

A vector store keeps embeddings and associated
document information so that relevant content
can be retrieved later.
